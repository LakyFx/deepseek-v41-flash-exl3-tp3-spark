# DS41F 1.2.2TF

This integrated production release combines the existing1.2.0/DeepSeek1017
TensorFold native recipe with the matching production gateway. The gateway
Python package version is1.2.2; the release and deployment label is1.2.2TF.

The gateway now processes up to **two independent image requests concurrently**.
Further accepted jobs wait in the existing bounded queue. Text shares the same
C12 admission gate. This does not limit a request payload to two images.

All other policy settings stay the same: vision MEDIUM, thinking3072,total6144,
900-second job deadline including queue, queue64, main MAX, admission5336064,
original image bytes, retained deduplication and UNKNOWN/no-automatic-replay.
An uncertain job blocks new image dispatch while an already running peer may
finish. Per-job results, cancellation and recovery remain independent.

Follow [the gateway guide](GATEWAY.md) for installation and operator-owned
persistent state/systemd configuration. The CLI and service template both
select two slots at startup. Upgrade with the same credentials and state;
the default job identity revision is retained across this scheduler update.
Only restart the gateway after draining active work. That gateway handles text
and vision, so restarting it can interrupt both; native model restart is not
required for this change.

Weights, Engram, native binaries, KV format,1.2.0 launcher profile and historical
benchmarks are unchanged. Use [the existing1017 recipe](DS41F-1.2.0.md) for the
native engine. The concurrency tests use mocked backends; no new throughput,
image latency, RAM measurement or power-cycle qualification is claimed.
