# TF351: Pollard routed experts, native TensorFold, TP3

TF351 is our selected TensorFold recipe for Hermes work. It keeps **Pollard routed experts at approximately 3.51 bpw**, combines them with the Mia-compatible ancillary EXL3 layout, and preserves the BF16 vision tower. It is a hybrid export, not a uniformly 3.51 bpw checkpoint.

- [Source, attribution, exact pins and technical explanation](TENSORFOLD-TP3.md).
- [Complete installation](TENSORFOLD-INSTALL.md).
- [Results, cache repairs and quality scope](TENSORFOLD-RESULTS.md).
- [Current profile: TF351 / 10M](../tensorfold/profiles/TF351.json).

The current profile is **10,000,000 logical pool tokens**, 401,408 request context, TP3, C8, MAX, 16 round rows and head snapshot budget 1 GiB. Generate the 10M RoPE tables on a CPU preparation machine, verify their qualified SHA values and distribute the exact kit to all ranks. The four tables have 10,002,432 rows each; changing the pool number without those tables is invalid.

The combined rank files occupy 257,715,943,020 bytes, approximately 85.9 decimal GB per node, plus local Engram, vision, kernel assets and preparation storage. This is disk size, not model VRAM use. Both recipes can coexist on disk, but they do not run concurrently in this qualification.

**14 October production repair:** the shipped kit includes six missing `_hc_mix_pf` row-4/5/6 variants, with the same weights and 10M pool. [Exact patch and acceptance](TENSORFOLD-HC-PREFILL-FIX.md). The new [real Hermes workload observations](HERMES-REAL-WORKLOAD.md) supplement the frozen comparative benchmarks; their five-hour TF window predates that repair.

## The frozen benchmark profile

Select `--variant TF351-3.3M` with its separate 3,301,376-row RoPE kit to reproduce the **configuration** of the final cache campaign. Identical settings alone do not guarantee identical output text, clocks, acceptance or timing. Some historical private legacy inputs are not published; available surrogate workloads are explicitly different.

```sh
python3 tensorfold/launch.py --config tensorfold/cluster.local.json --variant TF351 --rank 0
python3 tensorfold/launch.py --config tensorfold/cluster.local.json --variant TF351 --rank 1
python3 tensorfold/launch.py --config tensorfold/cluster.local.json --variant TF351 --rank 2
```

Those commands print only. Follow the installation guide before adding `--run` on each corresponding node. MAX is explicit on the head; the vision-medium policy is implemented by a gateway, not by globally lowering the model's main reasoning effort. TensorFold direct API and the separate vLLM gateway recipe are distinct components.
