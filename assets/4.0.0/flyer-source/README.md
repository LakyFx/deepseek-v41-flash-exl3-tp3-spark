# Editable TP3 / TP4 announcement artwork

`poster.html` is the original fixed-size 1920 x 1080 layout, with selectable
text, precise tables, CSS lighting/materials and a separate transparent
hardware illustration. Open it in a local browser or capture the `.poster`
element with Playwright after `document.fonts.ready`. A device scale factor
of 2 exports the 3840 x 2160 master. No external website, font download or
model/backend call is needed to display the layout. The reference render
uses Windows Segoe UI and Bahnschrift; other platforms use the CSS fallbacks.

`hardware-clusters.png` is an AI-generated illustrative product render of
three and four interconnected compact machines, not a photo of a measured
deployment. All benchmark numbers are real, retained measurements; see
[metric scopes and numerical records](../../../docs/SHORT-DECODE-4.0.0.md).

This graphic revision preserves the copy and metric definitions, removes
small-print footer paragraphs, and changes presentation only. The original
figures and complete methodology remain in the benchmark documentation.
